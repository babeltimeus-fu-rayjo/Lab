Spinning Wheel

A prize wheel you can reshape — set how many slices, how wide each one is, and how fast it spins. Then give it a flick.

Click the wheel or the hub to spin.

Wheel

The wheel lives in wheel.js next to this page: a canvas draws the slices with widths proportional to their weights, and spin() eases a CSS rotate() to a random angle, then reads which slice sits under the pointer. Slice count, per-slice width and spin speed all feed setConfig(). A wider slice is a bigger target, so it wins more often — exactly as a real wheel would.
